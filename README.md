Трекер задач на TypeScript
==========

Команды проверок
--------
* *dev* - выполняет код файла `src/main.ts` без проверки типов
* *typecheck* - осуществляет проверку типов
* *build* - создаёт JS-файлы и помещает их в папку *dist*
* *start* - выполняет код из файла `dist/main.js` 

Сценарии
--------

|Проверка|Критерий приёмки|
|--------|----------------|
|Пустое хранилище|Список пуст; статистика { todo: 0, doing: 0, done: 0 }|
|Создание с ' Разобрать union '|Успех; title без крайних пробелов; status todo|
|Заголовки null, 42 и пробелы|Ошибка; длина списка и следующий id не меняются|
|Длина заголовка 80 и 81|80 символов принимаются; 81 отклоняется|
|Поиск и изменение id 999|Поиск даёт undefined; изменения дают Result с
ошибкой|
|Обновление { title: ' ', priority: 'high' }|Ошибка; ни title, ни priority не изменены|
|Пустой patch и повтор текущего статуса|Оба вызова успешны и сохраняют значения|
|Создать A, B, A → doing; B → done|Статистика { todo: ..., doing: 1, done: 1 }|
|Изменить title в результате чтения|Внутренние данные сохраняют прежнее значение|
